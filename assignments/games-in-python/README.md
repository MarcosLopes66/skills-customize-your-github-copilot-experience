
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Construa um jogo da Forca em que os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas. Pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implemente o Jogo da Forca

#### Descrição

Escreva um programa em Python que implemente o jogo da Forca. O jogo deve escolher uma palavra secreta e permitir que o jogador tente adivinhá-la letra por letra.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear e exibir quantas tentativas incorretas restam.
- Encerrar quando a palavra for adivinhada ou quando as tentativas acabarem.
- Exibir uma mensagem indicando vitória ou derrota.
